2

愿意投入多少时间？

要不要云端存数据？

→ 要存储看类别③

类别一 · 视觉炸裂型

纯前端 · 最适合"展示一下"

这类项目几乎不需要后端，全靠 HTML/CSS/JS 的表现力。重点在"第一眼的震撼"，是你向别人展示技术审美的最直接方式。注意：视觉越重、资源越大，在国内慢速网络下体验越打折，做好权衡。

01

交互式 3D 个人主页 / 数字名片

视觉冲击 ★★★纯前端展示型
视觉冲击 ★★★★★
实用度 ★★★☆☆
把"关于我"做成一个可以探索的 3D 空间：访客像玩游戏一样移动镜头，逐个发现你的技能、经历和联系方式。这是"展示一下"这个需求的最强答案。
核心功能
  • 3D 场景：一个悬浮的星球 / 方块城市 / 画廊，每个元素代表一块内容
  • 鼠标视差 + 滚动镜头：移动鼠标场景轻微摆动，滚动触发镜头推进切换章节
  • 交互热点：点某个元素弹出技能详情、项目卡片、社交链接
  • 彩蛋：隐藏一个小动画或玩笑，让人愿意反复探索
视觉与动画设计
  • 深色霓虹配色（紫 / 青 / 粉），元素带发光描边和呼吸动画
  • 文字逐字浮现、粒子背景缓慢流动、镜头切换用缓动过渡
  • 首屏放一个"加载进度条"，本身就是一个炫技动画
技术实现
Three.js / react-three-fiber 建场景 · GSAP 做镜头动画 · 模型压缩后放 R2 或直接内联 · 纯静态托管即可
难度 高预计 3–5 天演进：2.5D 视差 → 加 3D 模型 → 加交互热点与彩蛋
02

滚动叙事故事页（Scroll Storytelling）

视觉冲击 ★★★纯前端
视觉冲击 ★★★★☆
实用度 ★★★☆☆
用"滚动"当遥控器讲一个故事——可以是你的成长经历、一个产品的诞生、甚至一个虚构小故事。每滚一屏，画面和文字跟着分镜切换，像在看一部交互电影。
核心功能
  • 分镜切换：多个全屏章节，滚动时固定镜头、内容滑入
  • 视差图层：前景、中景、背景以不同速度移动，营造纵深
  • 进度指示：侧边或顶部一条随滚动填充的进度条
  • 数据驱动动画：滚到某处数字从 0 滚动到目标值、图表生长
视觉与动画设计
  • 每个章节一个主题色，滚动时背景平滑渐变过渡
  • 关键文字用"遮罩揭示"效果（像 curtains 拉开）
  • 可加音效开关，增强沉浸感
技术实现
GSAP ScrollTrigger / 原生 CSS scroll-timeline · 图片序列或 CSS 图形 · 纯静态
难度 中预计 2–3 天演进：先做 4–5 屏线性叙事 → 加横向滚动 → 加分支选择
03

生成艺术 / 创意代码画廊

视觉冲击 ★★★纯前端
视觉冲击 ★★★★★
实用度 ★★☆☆☆
一组用算法"画"出来的视觉作品：粒子风暴、分形树、流体色彩、几何律动。每次刷新都不一样，是纯粹展示编程之美的地方。
核心功能
  • 多个作品：网格展示 6–12 个不同的生成艺术效果
  • 参数交互：滑杆调节颜色 / 密度 / 速度，实时看变化
  • 导出图片：一键把当前画面存成 PNG
  • 随机种子：显示当前 seed，可复现同一作品
视觉与动画设计
  • 全屏沉浸式画布，作品本身就是要展示的东西
  • 鼠标悬停加速 / 扰动效果，让人忍不住玩
技术实现
Canvas 2D / WebGL · p5.js 或原生 · 每个作品一个独立 JS 模块 · 纯静态
难度 中预计 2–4 天演进：先做 3 个效果 → 加参数面板 → 加导出与画廊分类
04

数据可视化大屏

视觉冲击 ★★☆实用 ★★☆可接数据
视觉冲击 ★★★★☆
实用度 ★★★★☆
把某类数据做成会动的仪表盘：可以是你工具的访问统计、某个公开数据、甚至模拟的实时数据。科技感强，也确实有用。
核心功能
  • 多种图表：折线、柱状、饼图、地图、词云
  • 数字滚动动画：关键指标加载时从 0 递增
  • 自动轮播：每隔几秒切换聚焦的图表
  • 实时感：用定时器模拟数据流入（或用真实 API）
视觉与动画设计
  • 深色科技风 + 发光图表 + 网格背景
  • 图表入场动画、数字跳动、警示色高亮异常值
技术实现
ECharts（上手快）或 D3.js（更灵活）· 数据源先用静态 JSON，后续可接 D1 / Workers
难度 中预计 2–3 天演进：静态假数据 → 接真实数据源 → 加定时刷新

类别二 · 实用工具型

延续你现有工具箱 · 最容易做

你已经有一个"在线工具箱"的雏形了，这条线最顺势。关键是：这类工具全部能在浏览器本地计算，不依赖服务器——所以在你国内访问偏慢的现状下，反而体验最好（文件不用上传下载）。

05

全能在线工具箱 2.0

实用 ★★★纯前端延续现有
视觉冲击 ★★☆☆☆
实用度 ★★★★★
把现有工具箱做深做全，做成"遇到小问题就打开它"的那种站点。工具越多、越顺手，用户越会回来——这是少数能自然积累访问量的方向。
核心功能（挑 15–25 个）
  • 开发类：JSON 格式化 / 校验、Base64 编解码、URL 编解码、哈希计算、正则测试、JWT 解析
  • 图片类：压缩、格式转换（WebP/PNG/JPG）、裁剪、二维码生成 / 识别
  • 文本类：字数统计、大小写转换、文本去重、Diff 对比、中文转拼音
  • 生活类：时间戳转换、倒计时、颜色选择器 / 配色方案、密码生成器
视觉与交互设计
  • 卡片网格 + 分类标签 + 搜索框，找工具要快
  • 即时响应：输入即出结果，不点按钮；成功状态给个轻微动效反馈
技术实现
全部浏览器 API + 开源库（如 jsQR、crypto-js）· 纯静态 · 零后端 · 加载极快
难度 中预计 逐个加，1–3 天起演进：先打磨 5 个常用工具 → 加搜索 → 加"最近使用" → 慢慢扩到 25 个

在线图片工作台

实用 ★★★纯前端
视觉冲击 ★★★☆☆
实用度 ★★★★★
浏览器里的轻量 PS：拖拽图片进去，裁剪、加滤镜、加文字水印、转格式，全程不上传——隐私好、速度快，用户很吃这一套。
核心功能
  • 基础编辑：裁剪、旋转、翻转、缩放
  • 滤镜：黑白、复古、锐化、亮度对比度，一键预设
  • 叠加：加文字、加图片水印、加边框
  • 输出：格式转换、质量调节、批量处理
视觉与交互设计
  • 大拖拽区 + 实时预览画布 + "前后对比"滑块（左右拖动看效果）
  • 操作按钮带悬停微动效，让工具也有手感
技术实现
Canvas API 或 fabric.js（功能全、交互好）· 纯前端 · 图片不离开用户设备
难度 中预计 3–4 天演进：基础裁剪 → 加滤镜 → 加文字水印 → 加批量
07

Markdown 写作台

实用 ★★★可本地 / 可云端
视觉冲击 ★★★☆☆
实用度 ★★★★☆
一个让人想写东西的编辑器：左边写 Markdown，右边实时预览，自动保存到本地；想更进一步就加云端同步，变成自己的笔记库。
核心功能
  • 分屏预览：实时渲染，滚动同步
  • 写作辅助：大纲导航、字数统计、夜间 / 专注模式
  • 导出：HTML、PDF、带样式的 MD
  • 存储：本地自动保存（localStorage / IndexedDB）；进阶版同步到 D1
视觉与交互设计
  • 极简排版、舒服的行距和字体、柔和的主题色
  • 输入时轻微的打字反馈、保存状态的小提示
技术实现
marked / markdown-it 渲染 · CodeMirror 编辑器 · 本地存储起步，进阶用 D1 云同步
难度 低–中预计 2–3 天演进：本地编辑器 → 加多文档管理 → 加 D1 云端同步和登录

类别三 · 完整应用层

用上 KV / D1 / R2 · 体现全栈能力

这类项目有真正的"后端"——但它不是传统服务器，而是 Cloudflare 的无服务器产品。你之前问过"没有服务器怎么云端存储"，下面这些就是答案的实战版。注意：这类应用每次交互都要走网络，在你国内访问偏慢的现状下，体验会受影响；想做好建议配合备案 + 国内 CDN。

08

短链接生成器

云端存储 ★★☆Workers + KV
视觉冲击 ★★☆☆☆
技术展示 ★★★★☆
输入长链接，生成一个短链接；别人访问时瞬间跳转。经典的全栈入门项目，代码量不大，但能把"计算 + 存储 + 边缘分发"完整跑通。
核心功能
  • 缩短：生成 6 位短码，自定义后缀
  • 跳转：访问短链时 301 跳到原地址
  • 统计：点击次数、时间、来源（存 D1）
  • 管理：二维码生成、有效期、删除
视觉设计
  • 一个输入框 + 结果卡片 + 统计面板，干净利落
  • 生成成功时短链和二维码一起弹出，带个 scaling 动效
技术实现
Worker 处理跳转与 API · KV 存"短码→长链"映射（全球低延迟读取）· D1 存点击日志 · 免费额度完全够用
难度 中预计 2–3 天演进：缩短+跳转 → 加统计 → 加自定义后缀与登录
09

匿名留言墙 / 时光胶囊

云端存储 ★★★视觉 ★★☆
视觉冲击 ★★★☆☆
技术展示 ★★★★☆
访客可以匿名留下文字或图片，贴在一面会动的墙上；"时光胶囊"模式则设定一个开启日期，到期前谁都看不到内容。互动性强，适合朋友间传播。
核心功能
  • 留言：昵称（可选）、文字、图片附件
  • 展示：便利贴 / 漂流瓶式的卡片墙，新留言有飘入动画
  • 时光胶囊：设定开启时间，到期才显示
  • moderation：简单的内容过滤 / 管理员删除
视觉与动画设计
  • 便利贴错落排布、hover 轻微旋转放大、新留言掉落动画
  • 时光卡片未解锁时显示倒计时和模糊遮罩
技术实现
Worker 提供 API · D1 存留言文本 · R2 存图片（免费 10GB）· 前端瀑布流展示
难度 中预计 3–4 天演进：文字墙 → 加图片 → 加时光胶囊 → 加简单审核
10

临时文件传输 / 私密网盘

云端存储 ★★★Workers + R2
视觉冲击 ★★☆☆☆
实用度 ★★★★★
上传文件后生成一个提取码和链接，对方凭码下载；可设有效期和下载次数，到期自动删除。比发微信文件更清爽，也是展示对象存储的绝佳例子。
核心功能
  • 上传：拖拽上传、进度条、大小限制
  • 分享：生成提取码和链接，可设密码
  • 控制：有效期、最大下载次数、到期自动删除
  • 下载：凭码取件，显示剩余次数
视觉设计
  • 大拖拽区 + 上传进度环 + 结果卡片（链接一键复制）
  • 复制成功的小动画反馈
技术实现
Worker 处理上传下载逻辑 · R2 存文件（零出站流量费，这点很香）· KV / D1 存提取码元数据 · 定时任务清理过期文件
难度 中预计 3–5 天演进：单文件上传 → 加提取码控制 → 加批量与过期清理

网址导航 / 书签收藏夹

实用 ★★★可云端
视觉冲击 ★★★☆☆
实用度 ★★★★☆
把自己常用的网址整理成一个漂亮的个人导航站，分类、搜索、点一点就打开。可以纯本地，也可以做成带云端同步的多人书签服务。
核心功能
  • 分类管理：分组、标签、搜索、排序
  • 自动信息：自动抓取网站图标（favicon）和标题
  • 点击统计：记录热门网址

视觉设计

技术实现
纯前端 localStorage 起步（零后端）· 进阶用 D1 存书签 + Worker 同步 · favicon 用 Google/第三方 favicon 服务或代理
难度 低–中预计 1–2 天（本地版）演进：静态导航 → 加搜索分类 → 加 D1 云同步

技术博客 / 个人作品集

实用 ★★★纯静态
视觉冲击 ★★★☆☆
长期价值 ★★★★★
把你的思考、学习记录、做过的项目沉淀成一个站。它不会一夜爆红，但半年后回头看，是最有积累价值的东西——也是简历上最硬的链接。
核心功能
  • 文章：列表、标签、搜索、归档、阅读时间估算
  • 写作：用 Markdown / MDX 写，代码高亮、目录自动生成

视觉设计
  • 留白充足、字体讲究、配色克制——"安静的高级感"
  • 文章卡片入场淡入、页面切换平滑过渡
技术实现
Astro / Hugo / Next.js 静态导出 · Markdown 内容 · 全静态托管，国内访问配合 CDN 极快
难度 低预计 1–2 天搭好，持续写演进：先发 3 篇 → 加标签搜索 → 加评论（可用第三方）

视觉冲击 ★★★★☆

  • 瀑布流入场错落淡入、灯箱切换的滑动动效
技术实现

难度 低–中预计 2–3 天演进：静态画廊 → 加分类筛选 → 加灯箱与 EXIF

视觉冲击 ★★★☆☆

趣味测试 + 结果卡片分享

纯前端视觉 ★★★
视觉冲击 ★★★★☆
传播性 ★★★★★
做个 8–12 题的趣味测试（人格、口味、"你是哪种 XX"），答完生成一张漂亮的结果卡片，用户会忍不住截图发朋友圈——这是传播性最强的类型。
核心功能
  • 答题流程：一题一屏、进度条、动画过渡
  • 结果计算：按选项加权算出类型
  • 结果卡片：Canvas 生成精美图片，含类型名、描述、标签
  • 分享：长按保存 / 下载图片
视觉与动画设计
  • 题目切换的滑入动画、选项点击反馈、结果揭晓的"开箱"感
  • 结果卡片设计要足够好看——这是用户分享的动力
技术实现
纯前端逻辑 · html2canvas / 原生 Canvas 生成分享图 · 静态托管，零成本
难度 低–中预计 2–3 天演进：一套测试 → 结果图优化 → 做成一个题库支持多套测试

每日一言 / 运势签

纯前端视觉 ★★☆
视觉冲击 ★★★☆☆
制作难度 ★☆☆☆☆
最小可执行的项目：每天一句随机名言 / 抽一支运势签，配一张好看的渐变卡片。一天就能上线，适合"先做个东西出来"破除拖延。

静态 JSON 文案池 + 前端日期算法 · 纯静态 · 进阶可用 Workers AI 实时生成文案
难度 低预计 半天–1 天演进：每日一言 → 加抽签动画 → 加分享图 → 接 AI 生成

🐢你的站点现在慢在哪

实测 `zqf.ltd` 国内访问绕到欧洲节点（阿姆斯特丹/伦敦），延迟约 205ms。所以纯静态、本地计算的项目（类别①②⑤）体验最好；需要频繁请求后端的项目（类别③）会放大这个短板。

📄备案决定上限

想让国内访问变快，最终要靠"域名备案 + 国内 CDN"。如果 `zqf.ltd` 没备案，就优先做不依赖网络的展示型项目；备案后可考虑迁国内 CDN，延迟能从 205ms 降到 20–30ms。

🔤立刻能改的一点

你页面里有 preconnect fonts.googleapis.com，国内会拖慢。无论做哪个项目，先把它去掉、字体本地化——这是投入产出比最高的优化。

🎯一个项目做精 > 十个半成品

别同时开五个坑。挑一个，做到"能发给朋友看且不掉链子"的程度，再开下一个。完成感比完美主义重要。

🆓成本几乎为零

Cloudflare 免费额度：Workers 每天 10 万次请求、R2 10GB、D1 5GB、KV 1GB。上面所有项目在个人用量下都能白嫖，不用买服务器。
